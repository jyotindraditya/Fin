<h1>Fin</h1>
This is a full stack web app(as of now) for tracking all your expenses. With a database that stores user login and expense data for convenience and privacy. The cloud hosted web app lets you access and note down your spendings anywhere.

<h3>Backend:</h3> Java Spring Boot REST API with JWT authentication
<h3>Frontend:</h3> React(built with Vite) that can also run as a desktop app via Tauri
<h3>Database:</h3> PostgreSQL
<h3>Hosting:</h3> Render(Frontend, API, Database)
